# Scout mascot system

Scout is the visual mascot for **STAC Scout**.

The character is a small field-scout beetle with a geospatial scanner, layered shell plates, and a
slightly skeptical expression. The goal is to give the project a recognizable open-source face
without turning the README into a product landing page.

## Character

Scout should read as:

- curious;
- technical;
- calm;
- slightly skeptical;
- more field tool than chatbot.

The character is not a debugging ladybug and should not be drawn as a generic AI robot.

## Visual language

Core features should stay stable across new artwork:

- dark navy / charcoal body;
- cyan scanner eye and small cyan accents;
- two antennae;
- layered shell plates;
- compact geospatial scanner or terminal;
- simple explorer / field-kit details;
- one half-lidded eye or similarly understated expression.

The layered shell is a loose visual nod to STAC's Collection → Item → Asset structure. It is not a
literal UI diagram.

Green, amber, and red are status accents only. The normal mascot should remain mostly
midnight/slate/cyan.

## Usage rules

- Prefer transparent-background art.
- Keep large mascot art to one or two pieces per document.
- Do not bake paragraphs, slogans, version numbers, or command output into the artwork.
- Keep technical labels in Markdown, where they stay searchable and editable.
- Do not use the mascot as a substitute for an architecture diagram.
- Do not imply that Scout is an AI assistant.
- Avoid excessive neon / cyberpunk styling; this is a geospatial developer tool.
- Keep alt text descriptive and short.

## Suggested poses

Future artwork can extend the same character into four small actions:

- **Find** — scanning catalog cards or map layers;
- **Verify** — inspecting an Item footprint;
- **Plan** — organizing raster/assets into a stack;
- **Replay** — comparing two saved map states.

Those actions should stay visually simple. The README owns the text labels.

## Naming

The project is **STAC Scout**.

The mascot is simply **Scout**.

Avoid introducing a second product name such as "ScoutBot" or "STAC Bug".
