# Contributing

Keep changes narrow, tested, and traceable to a concrete STAC or geospatial behavior.

## Local checks

```bash
ruff check .
ruff format .
mypy
pytest --cov=stac_scout --cov-report=term-missing
python evals/runner.py
python -m build
```

## Conventions

- Prefer small pure functions for normalization, identity, task derivation, and verification logic.
- Keep provider quirks behind catalog adapters.
- Keep provider and task registries declarative and packaged with the library.
- Do not add a dependency when the standard library is sufficient.
- Do not make recommendation logic depend on prose generated by a model.
- Represent unavailable metadata as unknown rather than guessing a value.
- Do not silently collapse probable cross-provider duplicates.
- A new task rule must distinguish required from preferred inputs, include rationale, cite authoritative sources where available, and add an evaluation case.
- Task rules must not invent event dates, comparison windows, or sampling cadence.
